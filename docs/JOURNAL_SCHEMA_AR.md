# مخطط سجل التداول

## الغرض

`TradeJournal.mqh` هو نقطة التسجيل الموحدة في EA. يسجل قرارات الانتظار والدخول والرفض ونتائج التنفيذ في CSV داخل مجلد `MQL5/Files`، ولا يسمح بكتابة سجل دخول إذا كانت الإشارة أو خطة الصفقة ناقصة.

## الحد الأدنى الإلزامي

كل سجل يحتوي على وقت الحدث، نوع الحدث، Build ID، معرف الإشارة، الاستراتيجية وإصدارها، الرمز، الفريم، الحالة، الاتجاه، قيم الدخول والوقف والهدف، الخطر النقدي، الحجم النظري والفعلي، نسبة العائد إلى المخاطرة، سبب القرار والتفاصيل.

## الأحداث الحالية

| الحدث | المعنى |
|---|---|
| `DECISION` | قرار الاستراتيجية، ويشمل WAIT أو ENTER أو INVALID أو EXPIRED. |
| `EXECUTION` | نتيجة محاولة الإرسال، بما فيها retcode والحجم والسعر الفعلي. |

## سياسة النقص

إذا كان Build ID أو strategy ID أو version أو symbol أو وقت الشمعة ناقصًا، يرفض السجل. وإذا كانت الحالة `ENTER` فلا بد من اتجاه وسعر دخول وخطة كاملة تشمل SL وTP والمسافة وRR والحجم.

هذه الآلية تمنع وجود صفقات بلا تفسير، لكنها لا تثبت صلاحية القرار أو الربحية. ذلك يأتي لاحقًا من Strategy Tester وDemo وMFE/MAE.
